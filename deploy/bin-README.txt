Put the tools the server uses here (or have them on PATH):
  yt-dlp   ffmpeg   deno
On Windows they are yt-dlp.exe, ffmpeg.exe and deno.exe. On Linux they are plain "yt-dlp", "ffmpeg", "deno".
On Ubuntu / Debian run "sh install.sh" from the folder above: it downloads yt-dlp and deno here and installs ffmpeg with apt.
See DEPLOY.md.
